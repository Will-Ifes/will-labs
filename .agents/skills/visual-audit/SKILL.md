# Auditoria visual localizada

Compare a mesma view, tema, viewport e estado de interação. Use capturas equivalentes quando o navegador estiver disponível. Liste diferenças observáveis em ordem de impacto: layout e hierarquia, proporções, tipografia, cor, espaçamento, estados. Separe observação de hipótese. Prefira uma comparação localizada; amplie a auditoria somente se a causa atingir componentes compartilhados. Não afirme paridade sem evidência.
