# Código de conduta

O Will Labs é um laboratório público feito para quem está aprendendo. Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/) em toda participação: issues, pull requests, discussões e revisões.

## O que esperamos

- Respeito com quem está começando. Pergunta básica é bem-vinda.
- Crítica ao código e às decisões, nunca às pessoas.
- Argumentos com evidência: teste, medição, link ou passo de reprodução.
- Cuidado com dados de terceiros: nada de expor informações pessoais.

## O que não é aceito

Assédio, ofensas, discriminação de qualquer natureza, ataques pessoais e publicação de dados privados de outra pessoa.

## Como relatar

Entre em contato de forma privada com o mantenedor pelo [perfil no GitHub](https://github.com/Will-Ifes) ou pelo [LinkedIn](https://www.linkedin.com/in/wildemberg-de-jesus-oliveira/). Relatos são tratados com sigilo. As medidas possíveis seguem as diretrizes de aplicação do Contributor Covenant: correção, advertência, suspensão temporária ou banimento.
