# Execução eficiente

Defina o resultado verificável e o menor conjunto de arquivos relevantes. Consulte `docs/agentes/contexto.md` e, para migração, `docs/plano/status-da-migracao.md`; não releia arquivos sem nova razão. Execute por partes quando o escopo for extenso, mantendo decisões e pendências em nota curta. Interrompa exploração improdutiva, evite ciclos de tentativa sem evidência e use validação direcionada. Encerre quando os critérios estiverem satisfeitos.
